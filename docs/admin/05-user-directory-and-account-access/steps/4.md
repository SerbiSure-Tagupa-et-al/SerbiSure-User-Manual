# Suspend an Account

1. Open **Account Access** and click **Manage access** for the user.
2. Under **Change access**, choose **Suspend account**.
3. Read the explanation. This blocks all app access, including support messages.
4. Click **Continue**, check the confirmation, then click **Confirm**.

To pause only resident chats, choose **Pause messaging** and **Pause for** instead. Support and Barangay messages stay open during a messaging pause.
