# Compare the Photo with the Document

1. Click **Compare Face** to open **Review applicant**.
2. Compare the profile photo with the face on the selected document.
3. Use the image zoom, rotate and move controls as needed.
4. Select another document with **Document to review** if needed.
5. Click **Done** when finished.

A generated avatar cannot be used for face comparison. Make your own visual check; this screen does not provide a biometric similarity score.
