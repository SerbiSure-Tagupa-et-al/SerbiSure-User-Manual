# Inspect the Scan and Read Details

1. Select the applicant's document in the review panel.
2. Read **ID Name**, **ID Type**, document number, **Date Issued**, **Validity** and **Status** where shown.
3. Click **Click to Zoom Scan** to enlarge the scan. Use **Rotate** if needed.
4. Compare the actual image with the extracted details and any **Flagged Discrepancies**.
