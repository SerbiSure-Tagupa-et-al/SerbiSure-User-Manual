# Set Up an LGU Account as Super Admin

1. Find a barangay marked **No Account**.
2. Click **Setup LGU**. Use **Add Barangay** when adding a new directory entry.
3. Check **Region**, **Province**, **City / Municipality** and **Barangay Name**. Fill in **House No. / Street / Zone / Subdivision** and **Official Desk Contact / Hotline Number** as needed. Check **Zip Code** and **Country**.
4. Review any **Jurisdiction Locked:** notice. Do not change an existing community's jurisdiction.
5. Click **Setup LGU Desk** after checking the details. For a new entry, click **Add Barangay**.
