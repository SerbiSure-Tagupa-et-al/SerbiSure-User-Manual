# Read & Download the SerbiSure User Manual

1. In the **SerbiSure User Manual**, switch between **Homeowner**, **Kasambahay**, and **Admin / Barangay** guides or open **All Flows (Complete Manual)**.
2. Tap **Download Word (.docx)** to download an offline Word document of the entire manual.
3. Tap **Print / Save PDF** to save or print a PDF copy for offline reference.
