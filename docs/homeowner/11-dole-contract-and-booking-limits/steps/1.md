# Monthly Short-Term Limit on Job Applications

1. SerbiSure caps short-term bookings at **7 days per booking** and at most **3 short-term bookings per month** between the same homeowner and Kasambahay pair.
2. If a 4th short-term application is attempted within the same month, the app displays **Application not confirmed**.
3. Tap **OK** and switch the engagement to **Long-term** using the **DOLE Standard Kasambahay Contract** workflow to continue hiring the same worker.
